# 拟真照片打印机任务清单

更新：2026-10-14。按用户要求拆分，当前推进首项；后续任务尚未实现。

## 视觉目标与边界

使用用户选定的哑光白色横向照片打印机：页面中央摆放机器，机身实体按钮触发，照片从黑色出纸口进入托盘。机器材质与接触阴影服务于拟真效果。最终方向为 Three.js 固定视角，不扩展旋转观察、内部机械仿真等功能。

原始参考：`prototypes/photo-printer/qa/reference.png`。调研：[外观与技术路线](logs/2026-10-14-photo-printer-technology-research.md)。

## T1 交付与验证

原型目录：`prototypes/photo-printer`。启动：该目录执行 `npm run dev -- --port 4173 --strictPort`。本次预览由代理启动，URL 为 `http://localhost:4173/`。

- 机身：ImageGen 生成的 RGBA 产品资产；没有生产 GLB。按钮用真实 DOM 入口与资产局部按压反馈，状态文字为 DOM。
- 相纸：Three.js 分段平面与动态照片纹理；送纸期间更新，静止按需渲染，卸载释放 GPU 资源。
- 样机用示例照片或本地选图，不调用小红书解析。相纸展示完整照片并按比例留白，下载直接给出输入图片。
- 浏览器验证：桌面 1440×1024、手机 390×844，实体按钮、打印禁用状态、完成、取片预览、Escape 关闭、重播与下载；控制台未见 error/warn。
- 生产构建通过；Three.js 使独立样机存在大于 500 kB 的单包警告，尚未做产品集成与移动设备性能实测。
- 证据和设计检查见 `prototypes/photo-printer/design-qa.md`。

T1 是验证造型与节奏的混合样机，不代表完整 3D 机身或真实解析已经完成。下一项是 T2；先完成静态机器模型和材质，再接同一段出纸交互。
