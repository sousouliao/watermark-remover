# 产品契约

## 用户目标

上传有水印的图片，选择 Seedream 5.0 Lite 或 Flash，得到可检查和下载的处理结果。处理应优先保留非水印区域的人物、文字、构图、颜色与纹理。

## 新版流程

使用指定 GitHub 账号登录后进入现有图片处理页面。前端加入登录/退出和统一 API 地址，现有处理布局保持不变。

1. 上传现有产品支持的图片。
2. 选择模型并直接处理；需要指明位置时，可在原图上手绘标记后处理。
3. 对比原图与结果，查看实际使用的模型；不满意时返回编辑或切换模型重试。
4. 下载确认后的结果。

## 验收边界

- 两款模型都能从同一产品流程明确选择和调用。
- 页面默认选择 Lite，用户可明确切换到 Flash；两款模型均通过同一处理流程调用。
- “水印已移除”与“原图其他区域保持”分别检查；不能仅凭模型返回图片判定成功。
- 指定区域将手绘标记转为包围框，帮助模型定位；它不等同于传统二值蒙版，也不保证区域外像素不变。
- 保留上传、结果对比与下载的核心功能。自动识别水印、账号计费与自建推理不属于本轮重构。

分阶段实施和验收条件见[路线图](../roadmap.md)。

## 小红书下载后端

当前已实现单条公开图文分享内容解析、单图预览/下载和全图集 ZIP 的 Go API，本轮不新增小红书页面。仅使用匿名解析服务返回的候选媒体资源，不保证作者原始文件或隐藏水印；单图、短链和长期可用性以实际验收为准。图集按返回顺序下载，失败不交付部分 ZIP；结果过期提示重新解析。生产必须先通过真实登录及 Go 云端下载验收，不能只凭解析器历史验证标记产品已上线。
