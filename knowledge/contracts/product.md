# 产品契约

## 用户目标

上传有水印的图片，选择 Seedream 5.0 Lite 或 Flash，得到可检查和下载的处理结果。处理应优先保留非水印区域的人物、文字、构图、颜色与纹理。

## 新版流程

使用指定 GitHub 账号登录后进入现有图片处理页面。前端加入登录/退出和统一 API 地址，现有处理布局保持不变。

1. 上传现有产品支持的图片。
2. 选择模型并直接处理；需要指明位置时，可在原图上手绘标记后处理。
3. 对比原图与结果，查看实际使用的模型；不满意时返回编辑或切换模型重试。
4. 下载确认后的结果。

## 验收边界

- 两款模型都能从同一产品流程明确选择和调用。
- 页面默认选择 Lite，用户可明确切换到 Flash；两款模型均通过同一处理流程调用。
- “水印已移除”与“原图其他区域保持”分别检查；不能仅凭模型返回图片判定成功。
- 指定区域将手绘标记转为包围框，帮助模型定位；它不等同于传统二值蒙版，也不保证区域外像素不变。
- 保留上传、结果对比与下载的核心功能。自动识别水印、账号计费与自建推理不属于本轮重构。

分阶段实施和验收条件见[路线图](../roadmap.md)。

## 小红书解析与下载前端及底部 Dock 导航

已实现小红书前端解析与下载页面（`XHSApp`），并通过底部 beUI `Dock` 组件与图片去水印工作台无缝切换：
1. **链接/分享文本解析**：支持粘贴小红书公开图文分享文案或链接，调用后端 `/api/xhs/parse` 进行匿名解析；
2. **安全受控流式下载**：前端通过注入 Bearer 凭据的 `apiFetch` 提取受保护资源为 Blob，消除直接 `<a>` 标签引起的 401 鉴权问题，提供单图下载与全套 ZIP 打包下载；
3. **直接下载原图**：解析获取的图片无需再次去除平台水印，结果卡片仅提供下载，不再提供“去水印”导入入口；图片去水印工作台仍可通过底部导航独立使用。未出结果时解析区在顶栏下方的可用页面区域水平、垂直居中，首次解析期间保持居中；解析输入使用 beUI `Input`，粘贴/清空使用官方 `Button`，解析及下载使用官方 `StatefulButton` 的原生 loading；
4. **视觉与交互规范**：严格贯彻 Monochrome Studio 单色工作室与 Zero-Shadow 规范，采用 beUI 原生 `Dock`、`AnimatedBadge`、`ReasoningText`、`Loader`、`Alert`、`Input`、`Button` 与 `StatefulButton`。图片预览使用 beUI 官方 `ImageViewer`（`morphing-lightbox`），支持缩略图展开、缩放拖动、图集切换与 Esc 关闭。
