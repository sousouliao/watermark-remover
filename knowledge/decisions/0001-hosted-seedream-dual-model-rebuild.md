# 决策 0001：托管 Seedream 双模型重构

- 状态：已接受
- 日期：2026-09-23

## 背景

原项目用手绘蒙版和 IOPaint-LaMA 做图像修复。用户希望推进全面重构，继续保留去水印产品功能，并同时支持截图所示的 Doubao Seedream 5.0 Lite 与 Flash。低频、随时使用的场景要求服务能够按调用使用，无须人工开关 GPU。

## 决策

1. 以火山方舟的托管图像编辑能力接入 Lite 和 Flash，二者均为用户可选模型。
2. 重构产品主流程为直接移除，并保留手绘指定区域的能力；不把旧二值蒙版直接当成新模型的原生参数。
3. 沿用 Vue 3 和 NestJS，先完成模型与产品链路；新链路可用后删除 IOPaint 运行依赖。
4. 用真实样本比较残留、非目标区域变化、耗时和费用，再决定默认模型。Flash 的官方发布定位不等于本项目的效果结论。

## 取舍与待验证

托管 API 降低了个人项目的部署与待机负担，但处理费用、上游限制和输出保真需实测。当前未确定两款模型的账号可用性、Flash 实际价格及局部编辑的稳定性；这些属于[路线图阶段 0](../roadmap.md#0-核对-api-与建立样本集)的验收内容。
