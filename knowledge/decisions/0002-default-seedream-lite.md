# 0002 · 默认使用 Seedream 5.0 Lite

日期：2026-09-24

页面上传图片后默认选择 Lite，用户仍可切换到 Flash；后端 API 继续要求请求显式携带模型，不做自动切换。

阶段 0 的 20 张样本对照显示 Flash 通常更快、区域模式框外像素差更小，但 19 号花朵样本的局部细节被明显抹平。阶段 3 再用其中五张代表样本通过实际产品接口运行两模型、两种模式，20 次请求均成功；19 号样本中 Flash 的直接和指定区域结果仍抹平花心颗粒，Lite 保留更多可见纹理。项目的[决策规则](../roadmap.md#决策规则)要求先看保真，再看速度和费用，因此暂以 Lite 为默认。请求记录和对照图见[阶段 3 报告](../../reports/model-eval/2026-09-24-product-path/index.html)。

这只是在现有许可样本上的默认选择，不代表 Lite 在所有图片上效果更好。两款模型都可能重绘水印外内容；遇到效果不佳时用户可切换模型或指定区域重试。
