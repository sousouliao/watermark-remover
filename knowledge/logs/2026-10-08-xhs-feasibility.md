# 小红书图片下载第一轮可行性验证

## 实现

新增独立 [HTTP 验证脚本](../../scripts/xhs-verify.ts)、针对性测试及[复跑说明](../../scripts/README.md)，未接入现有业务页面/API，也没有调用 Seedream。沿用 Node.js / TypeScript 和现有 tsx，不新增依赖。

脚本识别分享文本、校验每次重定向、校验并绑定公网 DNS 地址，读取 JSON 形式的 INITIAL_STATE（支持字符串外 undefined，不执行页面代码），匹配目标笔记，串行下载预览和实验性候选资源。限制请求超时与大小，按内容识别 PNG/JPEG/WebP 格式与文件头尺寸；完整解码、顺序、画质和可见水印仍需人工验收。候选规则未匹配或下载失败不算无水印下载成功。

私有输入、资源 URL、报告及下载文件仅写入 Git 忽略的 `.local/xhs-verification/`，不保存原始 HTML，不把分享 token 写入知识库。公共 DNS 为显式可选模式，不修改系统网络设置。

## 真实样本结果

用户提供了 5 条新复制的公开笔记网页分享长链接，来自不同作者；本轮没有真实短链样本，单图/多图数量尚未取得，不能声称已经覆盖实测。

| 本机方式 | 样本数 | 结果 |
| --- | --- | --- |
| 系统 DNS | 5 | 全部在请求前被公网地址校验拒绝；系统将 www.xiaohongshu.com 解析为 198.18.1.207 和 2001:2::1b4 等保留地址，与代理虚拟 DNS 特征一致 |
| 公共 DNS（Cloudflare DoH） | 5 | 全部最终跳转到 www.xiaohongshu.com/login；错误类别 access-restricted，尚未取得笔记数据 |

因此本轮真实样本笔记解析成功 **0/5**，下载图片 **0 张**，无水印、尺寸与完整解码均**未验收**。不能断定分享 token 失效，也不能推断换浏览器或服务器一定成功。已证实本机当前匿名 HTTP 路径无法直接跑通这些样本。

## 验证与结论

针对性离线测试覆盖链接识别与参数保留、重定向和非公网目标拒绝、两类笔记数据结构、安全 JSON 提取、资源候选规则、真实格式保存、图集顺序、候选失败与页面错误归类。7 项测试、脚本范围 ESLint、TypeScript 检查及 git diff --check 通过。离线模拟成功不计入真实样本成功率。

结论：**需追加验证，暂不进入产品实现。** 按本机先行计划，本机尚未通过，因此腾讯云对照未执行；服务器 SSH 接入信息也尚未提供。没有追加 Playwright、Cookie 或浏览器模拟。下一步应决定是否追加浏览器匿名访问对照或提前云端探针，以区分本机访问环境与站点访问策略；追加前需用户确定方向。本轮不进行产品 API、页面及 ZIP 开发。
