# React 前端迁移 PASS 1

## 范围与结果

按用户要求在 `apps/web` 原地替换 Vue 入口，包名保留 `@watermark-remover/web`，不创建第二个应用、不使用 TanStack Start、不修改 Go 服务、不提交或推送 Git。

- React 19 + Vite SPA，TanStack Router 文件路由 `/` 和 `/auth/callback`；生成并保留 `routeTree.gen.ts`。
- TanStack Query provider、Zustand 5 会话与认证，保留三个 sessionStorage key、PKCE 参数、中文错误和 `VITE_API_BASE_URL`。API 401 清除 token 与页面认证状态；回调交换在路由 `beforeLoad` 中执行，完成后 replace 跳转 `/`。
- Button（CVA/Slot）、Card、Input、Progress、Slider 改为 React TSX；保留主题 CSS、渐变背景、FOUC 脚本和 PWA 配置。
- pnpm 从根目录安装当前兼容版本。TypeScript 7 移除了 `baseUrl`，配置改用相对 `paths`，严格检查继承根配置。Vite 8 使用 `import.meta.dirname`。
- 删除 `main.ts`、`App.vue` 和全部 UI `.vue`。业务 Vue 页面/组件及三个 Vue hook 留待 PASS 2；当前入口未引用它们，三个 hook 在应用 tsconfig 中明确排除。当前业务页显示「水印移除工具（迁移中）」。

## 验证

- `pnpm install`：通过。
- `pnpm --filter @watermark-remover/web build`：通过，生成 SPA 和 autoUpdate PWA service worker。
- `pnpm --filter @watermark-remover/web type-check`：通过。
- 本轮前端改动文件 ESLint：通过；`git diff --check`：通过。
- Ego Browser 本地模拟 API 冒烟：未登录卡片、无效回调中文错误、有状态/校验码的成功回调（单次交换、清空 verifier/state、返回 `/`、显示用户与占位页）、`/api/auth/me` 会话恢复及 Bearer header、离线退出、401 清除 token/user/认证状态、PKCE SHA-256 challenge 和登录失败 busy/error 恢复均通过。

浏览器验证使用模拟响应，没有访问真实 GitHub 授权或验收线上 Go 服务。后续 PASS 2 迁移业务功能，PASS 3 完成整体验收。路由插件放在 React 插件前，依据 [TanStack Vite 安装文档](https://tanstack.com/router/latest/docs/installation/with-vite)。
