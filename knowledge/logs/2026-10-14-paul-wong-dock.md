# Paul Wong 底部胶囊还原

用户指定 https://www.paulwong.work/ 为视觉参考，并明确保留图片去水印、小红书解析功能。本次仅替换全局底部应用导航和迁移主题入口。

## 实现

- 新增 `AppDock/AppDock.tsx` 与组件自有 CSS，使用现有 Motion、Lucide，无新增依赖或后端改动。
- 现场读取参考 DOM/CSS：默认 301×61px、展开 420×61px、圆角 39px、底部 39px；主题组 115×35px，3 个 35px 按钮间距 5px；内边距 13/20/13/24px。
- 左侧改为本项目两个入口，悬停与键盘聚焦展开；中文采用 14px、500 中等字重的系统字体和现有应用图标，这是保留产品内容的有意适配。
- 右侧支持系统/浅色/深色主题，沿用 localStorage `theme`，系统模式监听媒体查询变化。顶栏移除重复主题按钮。
- 参考站的底部 239px 模糊区由 8 个遮罩 backdrop 层实现，0.1875→24px；不拦截指针。复刻细阴影与深色描边，作为 DESIGN.md 的局部例外。
- 主体底部留白调整为 239px，避免滚动到底时主要按钮停在虚化区；版权信息保持清晰。

## 验证

- TypeScript 检查通过；改动组件 ESLint 通过；前端生产构建通过。
- 真实浏览器验证：默认与展开尺寸、深浅主题、跟随系统即时变化、两个页面切换、导入本地样本后切换仍保留画布。
- 390×844 和 320×740 窄屏无横向溢出，两个应用名称和主题控制均可用；1280×700 滚动到底时胶囊距底部仍为 39px，操作按钮清晰。
- 交互期间采集的 error/unhandledrejection 无记录。后端 API 未调用，不包含模型/解析服务验收。
- 本地依赖原先缺失已声明的 motion；通过 frozen-lockfile 安装补齐，package.json 与锁文件均未改动。
- 对照图与浏览器证据见 `reports/ui/2026-10-14-dock/`；详细 QA 见根目录 `design-qa.md`。
