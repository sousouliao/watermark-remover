# 照片打印机 T1 实施与交付

日期：2026-10-14。

## 本次范围

用户要求落实打印机方向、拆分任务并推进下一项。T1 在 `prototypes/photo-printer` 建立独立 Product Design 样机，沿用已选白色机器；生产 `apps/web` 和业务 API 尚未改动。

生成透明无纸机身和沿海日落照片，保留真实 DOM 按钮与状态文字，使用 Three.js 分段平面/照片纹理完成送纸；支持启动、出纸、取片预览、原图下载、重播。修正状态屏对齐、相纸与托盘位置、手机按钮点击区域及取片后的相纸隐藏。

## 验证与限制

- 桌面1440×1024、手机390×844示例照片路径完成浏览器检查；已验证取片/Escape关闭、重播和下载，控制台 error/warn 查询为空。
- 通过原图与实现并列画面完成设计对照；证据、差异及修正见[设计检查](../../prototypes/photo-printer/design-qa.md)。
- `npm run build` 通过；Three.js 单包体积有大于500kB的提示。
- 本地选图入口已实现，但 IAB 文件选择器自动化等待超时，未完成自动上传验收。
- 未实现完整3D机身、真实解析图集、ZIP/送去水印接入，未做实际移动设备性能验收；没有发布。

## 接续入口

进度与后续验收统一维护在[打印机任务清单](../photo-printer-plan.md)。T1 已交付，下一项为 T2 完整3D机身、材质和光影。运行方式见[样机 README](../../prototypes/photo-printer/README.md)。
