# React PASS 2：水印业务迁移

## 实施

- `apps/web/src/pages/WatermarkApp.tsx` 接入上传 → 选择与编辑 → 结果流程；保留默认 Lite、Flash、直接与指定区域模式、返回编辑、重试及取消。
- ImageUploader、MaskEditor、ResultViewer、ActionBar、ProcessingOverlay、ThemeToggle、AppHeader、AppFooter 均迁移至 React TSX，使用 lucide-react 与现有 React UI primitives。界面与本地错误提示统一为中文，保留模型名称。
- `useWatermarkApp`、`useMaskEditor`、`useResultViewer` 改为 React hooks；移动端使用已有 `useIsMobile`，移除冗余 global store。
- 去水印仍通过认证 API helper POST `/api/watermark/remove`，传 image/model/mode，区域模式另传 region。切换、取消、重置及卸载均使请求失效并 abort，过期响应不会覆盖当前状态。
- 画布以原图坐标保存笔画，转换为 0–999 包围框；pointer capture 支持鼠标与触摸，保留笔宽、撤销、清空和缩放后的重绘。编辑器在处理及结果阶段保持挂载，保证区域重试与返回编辑可复用笔画。
- 结果保留滑块与并排对比、键盘操作、下载、POST `/api/upscale` 的 2 倍增强、撤销增强及缓存复用；卸载中止增强请求。对比图左右标签与实际显示一致。
- 删除所有 Vue 文件、临时 tsconfig 排除项。认证 store、routes、server 均未改动；没有提交或推送。
